# SolveTech Lab

## 🎯 Objetivo Clínico e Escopo
O **SolveTech Lab** é uma plataforma inovadora de gestão e monitoramento contínuo de saúde (atuando de forma genérica para diversas condições clínicas). O propósito fundamental do sistema é **centralizar dados clínicos dispersos** e cruzar métricas vitais, servindo como suporte à decisão clínica através de um dashboard médico integrado com IA para análise, monitoramento e disparo de alertas preventivos. 

*(Obs: Com foco inicial em Hipertensão e Diabetes, mas escalável para qualquer métrica vital).*

## 👥 Atores do Sistema
* **👤 Paciente:** Realiza o acompanhamento de sua própria saúde, registrando medições vitais genéricas (pressão, glicemia, peso, saturação, etc.) e visualizando seus agendamentos.
* **🧑‍⚕️ Profissional de Saúde:** Acessa os prontuários, analisa os dashboards de correlação clínica (auxiliado pela IA) e prescreve tratamentos/evoluções com base no histórico consolidado.
* **⚙️ Sistema de Notificação (IA):** Ator automatizado responsável por auditar métricas e disparar alertas em cenários de risco clínico.
